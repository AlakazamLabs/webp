# Security policy

Please report vulnerabilities privately, through GitHub's private
vulnerability reporting: on this repository's **Security** tab, choose
**Report a vulnerability**. Please don't open a public issue.

We will acknowledge the report, work on a fix privately, and publish the
fix and an advisory together. Until the advisory is out, release notes say
only that a release fixes a security issue.

Supported versions: the latest published release of each crate in this
repository.
